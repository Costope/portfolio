What I'm proud of

Valtro

A compound interest calculator I built because the tool I wanted didn't exist yet.

I wanted to see how long it'd take to hit certain financial goals, but couldn't find a simple calculator for it — so I built one myself.

It's a PWA — HTML, CSS, JavaScript — built to skip the App Store's bureaucracy and cost while still feeling fast and installable. The name comes from "Vault," and the .app domain signals it's a real working tool, not a static page.
