> **Overview:** A minimal, dark-themed developer portfolio crafted with plain HTML, CSS, and vanilla JavaScript. Built with a performance-first mindset, clean architecture, and zero bloat.

---

## Architecture & Features

* **Modern UI/UX:** Clean and dark design optimized for high readability.
* **Ultra Fast:** Zero heavy JavaScript frameworks — pure, lightweight web tech fast load times.
* **Serverless View Counter:** Powered by **Netlify Functions** and **Netlify Blobs** for persistent data without a complex database.
* **Rock-Solid Precision:** Handcrafted code, tested across modern browsers and responsive layouts.

## AI Usage

> [!NOTE]
> This project embraces AI as a modern developer tool while maintaining full human oversight.

AI (Gemini) was utilized as a technical assistant for:
- **Problem Solving:** Brainstorming edge-case fixes and architecture approaches.
- **SVG Optimization:** Refining vector icons and responsive scaling (`1em`, `currentColor`).
- **Layout Assistance:** Structuring CSS grids and flexbox patterns.
- **Code Cleanup:** Making JavaScript cleaner and easier to read.

*All AI-generated snippets were manually reviewed, audited, and tested prior to deployment.*
